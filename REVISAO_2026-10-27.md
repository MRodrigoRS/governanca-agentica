## 1. Erros Factuais Corrigidos

Comandos e estruturas foram escritos de memória e verificados contra as fontes oficiais.

| # | Onde | Escrito antes | Correto |
|---|---|---|---|
| F1 | PIVOT, PRESETS | `npx create-epic-stack@latest` | `npx create-epic-app@latest` (antes: `npx epicli`). **Confirmar no README oficial na hora de usar.** |
| F2 | PIVOT, PRESETS | `uvx create-fastapi-app` | Não existe. Oficial: `copier copy https://github.com/fastapi/full-stack-fastapi-template.git <nome>` |
| F3 | PIVOT, PRESETS | `npm create nestjs-app` | Não existe. Oficial: `npx @nestjs/cli new <nome>` |
| F4 | PIVOT | `npx create-t3-app@latest` | `npm create t3-app@latest` (ambos funcionam; esse é o documentado) |
| F5 | SÍNTESE | Pastas inventadas `specs/viva/` e `specs/arquivo/` | OpenSpec real: `openspec/specs/<dominio>/spec.md` (base viva) e `openspec/changes/<mudanca>/` (proposal, design, tasks, deltas), arquivadas em `openspec/changes/archive/` |
| F6 | PROPOSTA | Constituição em `.spec/constitution.md` | Spec Kit real: `.specify/memory/constitution.md` e features em `specs/NNN-nome/` |

**Correção de uma resposta no chat:** eu disse que é "rigorosamente verdade" que o Spec Kit exige teste falho. O mais preciso: o **princípio Test-First (teste falha antes do código) está no modelo de constituição e na filosofia do Spec Kit**, mas **a ferramenta não obriga nada**. Há uma issue na comunidade (#627) relatando que os agentes pulam a fase vermelha. Para virar regra de fato, a gente precisa colocar na nossa constituição **e** cobrar evidência (saída do teste falhando) no Gate 2, ou usar uma extensão tipo `spec-kit-tdd`.

## 2. Contradições Entre Documentos

| # | Contradição | Resolução aplicada |
|---|---|---|
| C1 | PROPOSTA e PRESETS dizem que um **script/CLI detecta a stack e escolhe o preset**; o PIVOT diz que **o agente decide após entrevista**. | Prevalece o PIVOT. O comando de instalação só injeta a governança. Quem escolhe a stack é o agente, na entrevista, com aprovação humana. |
| C2 | ARQUITETURA_PROGENITORA lista pautas futuras para "simplificar `ui.mjs`"; o PIVOT aposenta painéis e servidores. | Documento marcado como **análise do legado (v1)**. Pautas obsoletas removidas. |
| C3 | Os documentos usam **Spec Kit** (`spec.md`/`plan.md`/`tasks.md` por feature) e **OpenSpec** (base viva + deltas) ao mesmo tempo, como se fossem compatíveis. | **Não são somáveis literalmente:** dois conjuntos de comandos e de pastas para a mesma função. Virou a decisão pendente **P1**. |
| C4 | Arquivos de regras listados como `.cursorrules` + `CLAUDE.md` + `copilot-instructions.md`, cada um com conteúdo próprio. | `.cursorrules` está obsoleto (o Cursor usa `.cursor/rules/`). E o **`AGENTS.md` virou padrão aberto** lido por Copilot, Codex, Cursor, Gemini, Windsurf e Aider. Agora: **`AGENTS.md` é a fonte única**, e os demais arquivos são ponteiros finos. |
